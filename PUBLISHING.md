# Publishing status

This is a fresh standalone Watch Lock repository, with only system-password/PAM
authentication and the upstream fingerprint flow. A public source snapshot and
the listing at https://tools.danimoya.com/watch-lock/ are development previews.

The first publication contains no imported Git history. Screenshots are generated
from `preview/` fixtures, not from a real desktop. Review any new image before
adding it; avoid account names, notifications, private projects, history and secrets.

Do not label a version supported or submit it as an accepted marketplace release
until [RELEASE-CHECKLIST.md](RELEASE-CHECKLIST.md) is complete. A repository, a
personal website listing, marketplace submission and directory acceptance are
separate outcomes. Preserve upstream attribution and record the tested commit.
